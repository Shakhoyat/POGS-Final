## Scene
- New scene `tool_table`: the drill (`data/scene_generator/objects.py::power_drill`) on the
  benchmark's low table + floor, same materials, 35-view capture, own trained checkpoint.
  (The pick-place scene has no tool.) Static 889×500 camera, 5 Hz, as in the benchmark.
- Rotation about the drill's own vertical axis through its centroid (Q2: confirm axis);
  second axis (horizontal, through the grip) as a secondary condition.
- No occluder in the main condition (perturbation by an invisible agent); gripper case is O4.

## Trajectories (per seed: random start yaw ∈ [0, 360), random placement on the table)
- **Step-wise (supervisor):** x = rest (hold 5 frames) → +5° steps to +30° (state p), each step
  a 1-frame move then hold h = 3 frames → −5° steps back to 0° (state y) → hold 5 frames.
- **Single jump (paper Table II):** rest 5 frames → ±15° or ±30° within one frame → hold 15 frames.
- Step-size sweep for the step-wise protocol: 5°, 10°, 15° (same 30° total).

## Measurements (each tracked frame)
- Pose: position error (cm), geodesic rotation error (°), ADD-S (m), from `metrics/pose.py`.
- Splats: `metrics.gaussian.weighted_kl` between the GT-posed scan Gaussians and the tracked
  Gaussians of the drill group (matched indices; COV_EPS floor). **Stated in the report: under
  rigid motion this is a function of pose error.** Final splat comparison: KL(x ‖ y).
- GT-free: `kl_render` (to be implemented, PLAN 2.4) between observed and rendered feature
  distributions in the ROI.

## Success (fixed in advance)
- A trial **recovers** if, at the end of the final hold, position error < 3 cm AND rotation
  error < 5° (paper Sec. V-B), and no frame in the trial exceeds 10 cm (lost).
- Recovery angle = the largest step-wise peak angle (sweep 5..30° peaks, if Q2 allows) at
  which ≥ 80 % of trials recover.

## Methods and sample size
- Static (no motion), POGS (paper: DINO + depth), POGS (release: no per-frame depth),
  POGS + KF + check. 25 iterations. 5 seeds per condition (PLAN §3.3).
- Statistics: recovery rate with Wilson 95 % CI (`metrics/stats.py`); errors as mean ± seed std.
