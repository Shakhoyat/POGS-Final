# Shared Datasets Directory

This folder contains both synthetic generated scenes and real robot capture datasets.

## Subdirectories:
- `synthetic_scenes/`: Scenes generated by `scene_generator`.
  - Structure:
    ```
    synthetic_scenes/<scene_name>/
      ├── scene_catalog.json
      ├── capture/ (35 multi-view views, depth, masks, poses, fused_pointcloud.ply)
      ├── tracking_respected/ (<= 30° yaw, tracking_annotated.mp4, tracking_metadata.json)
      ├── tracking_threshold/ (~ 30° yaw boundary, tracking_annotated.mp4)
      ├── tracking_violated/ (> 30° yaw violation, tracking_annotated.mp4)
      └── tracking_servoing/ (15° and 30° pulses)
    ```
- `real_scenes/`: Real UR5 / ZED-2 captures downloaded from the author's Google Drive.
